# TapBeat

**Coming soon — a free drum pad and beat maker: 16 synthesised pads and a step sequencer. Private
and offline.** A free app on [FreeAppStore](https://freeappstore.online), live at
https://tapbeat.freeappstore.online.

Right now this is a shell: it lists the planned features, but none of them work yet. Progress is
tracked in
[freeappstore-online/platform#212](https://github.com/freeappstore-online/platform/issues/212).

## Develop

```bash
pnpm install
pnpm dev      # local dev server
pnpm build    # production build in web/dist
fas check     # FreeAppStore compliance checks
```

Pushes to `main` auto-deploy via GitHub Actions.
